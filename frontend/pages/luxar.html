Backend Development

Luxar

A business discovery platform designed to organize business information, manage records, and make details accessible through dedicated pages and QR-based access.

GitHub Repository Live Demo

The Problem

Business information such as contact details, opening hours, photos, menus, and facilities can be scattered across different platforms.

My Solution

Luxar is being developed as a platform for organizing business data through a structured backend API and database. Administrators can manage records, and visitors can access business information through dedicated pages.

Key Features

  • FastAPI backend and structured API endpoints
  • Create, read, update, and delete business records
  • PostgreSQL database integration
  • Restaurant and menu information management
  • Modular routers, schemas, and database models

Technology Stack

Python FastAPI PostgreSQL SQLAlchemy Pydantic HTML CSS JavaScript

What I Learned

  • Designing and organizing REST API endpoints
  • Connecting FastAPI with PostgreSQL
  • Validating data using schemas
  • Separating backend logic into reusable modules

Project Status

In development. Features and deployment will continue to improve as the project progresses.
