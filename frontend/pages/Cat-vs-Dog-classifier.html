Cat vs Dog Classifier

An image classification project that predicts whether an input image contains a cat or a dog. The application uses a trained image model and ONNX Runtime Web for inference.

Try Live Demo ↗ GitHub Profile ↗

The Problem

Identifying objects in images is a common computer vision task. A classification model learns visual patterns from labeled examples to distinguish between categories.

My Solution

I developed a cat-versus-dog image classifier using a trained neural network. The model can be used by the web application to generate a prediction from an image.

Key Features

  • Cat and dog image classification.
  • Image input through the web interface.
  • Trained model exported to ONNX format.
  • Browser-based inference using ONNX Runtime Web.
  • Live demo available online.

Technology Stack

Python PyTorch CNN ONNX ONNX Runtime Web JavaScript HTML CSS

What I Learned

  • How image classification works.
  • How neural networks learn visual features.
  • How to export models for deployment.
  • How to integrate a model into a browser application.

Project Status

A live demo is available. Model performance and generalization can be improved through additional training, data preparation, and evaluation.
