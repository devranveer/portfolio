Handwritten Digit Recognition

A machine learning project that recognizes handwritten digits from 0 to 9. The project uses a Convolutional Neural Network (CNN) and ONNX Runtime Web for browser-based inference.

Try Live Demo ↗ GitHub Profile ↗

The Problem

Handwritten digits can look different depending on a person's writing style. A computer needs a trained model to identify these digits from pixel data.

My Solution

I built a CNN-based digit recognition application. Users can draw a digit on a canvas, and the trained model predicts which digit it represents.

Key Features

  • Interactive canvas for drawing digits.
  • Canvas input processed for model prediction.
  • CNN model trained for digit classification.
  • ONNX model used for browser-based inference.
  • Real-time prediction workflow.

Technology Stack

Python PyTorch CNN ONNX ONNX Runtime Web JavaScript HTML CSS

What I Learned

  • How CNNs can be used for image classification.
  • How image input is prepared for model inference.
  • How to export a trained model to ONNX format.
  • How to integrate machine learning inference into a web application.

Project Status

An interactive demo is available online. The project can be improved further through model evaluation and prediction accuracy improvements.
